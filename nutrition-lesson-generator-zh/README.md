# 中文营养课程生成器 (Nutrition Lesson Generator — Chinese)

将营养主题转化为结构化中文课件包，导出可编辑 PowerPoint。默认完全离线，可选 PubMed 证据检索。

## 概览

| 项目 | 内容 |
|------|------|
| 版本 | v0.1.0 |
| 作者 | 王润圆（中国注册营养师） |
| 语言 | 中文（默认）/ English / 日本語 |
| 许可证 | MIT |
| 依赖 | Python 3.11+ |

## 功能

- 🎓 输入营养主题 → 输出完整中文课件包
- 📊 实时导出可编辑 PowerPoint（16:9 宽屏）
- 📋 9 页标准化课件结构（封面→目录→背景→概念→证据→实践→误区→总结→参考文献）
- 🔬 Mock 模式完全离线（内置中国营养指南证据 fixture）
- 🔗 可选 PubMed 模式（NCBI E-utilities 实时文献检索）
- 🛡️ 内置质量验证器（禁止疾病治疗语言、因果夸大检查）
- 🌏 千里江山图配色主题（青蓝 + 苍绿 + 赭金）

## 课件结构

| 页码 | 类型 | 内容 |
|------|------|------|
| 1 | 封面 | 主题 + 副标题 + 作者信息 |
| 2 | 目录 | 本课内容概览 |
| 3 | 背景 | 为什么关注该话题 |
| 4 | 概念 | 核心术语与定义 |
| 5 | 证据 | 科学证据一览表 |
| 6 | 实践 | 日常生活中的落实方法 |
| 7 | 误区 | 常见误解辨析 |
| 8 | 总结 | 关键要点回顾 |
| 9 | 参考文献 | 带 PMID/来源的引用列表 |

## 安装

```bash
pip install -r requirements.txt
```

## 使用

### 生成中文课程（离线 Mock 模式）

```bash
python -m src.main generate \
  --topic "膳食纤维与肠道健康" \
  --audience "普通成年人" \
  --duration 30 \
  --output-dir output
```

### 指定其他受众

```bash
python -m src.main generate \
  --topic "儿童青少年肥胖的膳食预防" \
  --audience "学龄儿童家长" \
  --duration 20
```

## 输出文件

```
output/
├── 课程规范.json       # 规范化课程包
├── 课程大纲.md         # Markdown 大纲
├── 讲稿.md             # 逐页讲稿
├── 参考文献.md         # 完整引用及出处
├── 质量报告.md         # 验证报告
└── 营养课程.pptx       # 可编辑 PowerPoint
```

## 安全红线

- ❌ 不提供医学诊断或治疗方案
- ❌ 不编造引用数据
- ❌ 不将观察性关联转化为因果声明
- ❌ 不推荐具体药物或补充剂剂量
