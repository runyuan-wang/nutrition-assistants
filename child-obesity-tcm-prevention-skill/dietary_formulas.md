## 一、气虚质药膳

### 1. 参芪鸡丝冬瓜汤

| 项目 | 内容 |
|------|------|
| 适用体质 | 气虚质 |
| 材料 | 人参、黄芪、鸡丝、冬瓜（适量） |
| 做法 | 煲汤食用 |

| 禁忌 | 感冒发热、阴虚火旺者慎用 |

## 三、痰湿质药膳

### 4. 荷叶茯苓粥

| 项目 | 内容 |
|------|------|
| 适用体质 | 痰湿质 |
| 材料 | 鲜荷叶1张、茯苓50 g、粳米50~100 g |
| 做法 | 加水熬粥 |
| 功效 | 健脾利湿，升清降浊 |
| 禁忌 | 体瘦阴虚者不宜多食 |

### 5. 冬瓜薏仁粥

| 项目 | 内容 |
|------|------|
| 适用体质 | 痰湿质 |
| 材料 | 冬瓜150 g、薏苡仁50 g |
| 做法 | 将冬瓜切小块，与薏苡仁加水共煮至熟 |
| 功效 | 健脾祛湿，利水消肿 |
| 禁忌 | 脾胃虚寒、孕妇慎用 |

## 使用说明

1. **食药物质用量**：所有食药物质用量请控制在指南推荐的范围内，不可超量长期使用
2. **体质确认**：使用前请确认孩子体质，不同体质对应不同药膳
3. **禁忌人群**：注意每种药膳的禁忌人群
4. **建议频率**：药膳建议每周2~3次，作为日常饮食的补充，不可替代正餐
5. **就医提醒**：体质辨识不清或有合并疾病时，建议咨询中医师或营养师
6. **免责声明**：以上药膳方仅供营养科普参考，不可替代药物治疗。使用前建议咨询专业人员
