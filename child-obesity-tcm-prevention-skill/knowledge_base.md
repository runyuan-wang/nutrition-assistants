## KPK-01：肥胖定义与流行病学

### 核心定义
儿童青少年肥胖是由于长期能量摄入超过人体消耗，使体内脂肪过度积聚、体重超过按身长计算的平均标准体重20%及以上的一种营养障碍性疾病。

### 流行病学数据
- 我国6岁以下儿童超重肥胖率：10.4%（2020年）
- 6~17岁儿童超重肥胖率可达：19.0%（2020年）
- 男性儿童患病率高于女性儿童，低龄儿童发病率有增高趋势
- 发展中国家儿童肥胖率逐年上升，有超过发达国家的趋势

### 肥胖的危害
肥胖不仅影响儿童外观体型，更会增加儿童患哮喘、糖尿病、高血压病、黑棘皮病、心理疾病及心血管疾病等的风险，且危害可持续至成年。

### 关键术语
- **超重**：体内脂肪积累过多，可能造成健康损害的一种前肥胖状态
- **肥胖（单纯性肥胖）**：由多种因素引起，体重超过平均标准20%及以上
- **肥胖高危儿童**：有肥胖家族史、不良生活方式等危险因素，或已超重但未达肥胖标准

## KPK-02：危险因素筛查

### 三大危险因素

**1. 先天因素（遗传）**
- 遗传因素占肥胖原因的20%~40%
- 父母肥胖与儿童肥胖密切相关
- 遗传易感性需要与环境和行为因素共同作用才能导致肥胖

**2. 生活方式**
- **不良饮食行为**：不吃早饭、晚餐供能过甚、高脂饮食、暴饮暴食、常吃含糖饮料及快餐食物
- **活动不足**：体育活动时间过少
- **视屏时间过长**：看电视、玩游戏时间多
- **睡眠不足**：睡眠时间较晚或较少

**3. 精神心理因素**
- 心理应激和消极情绪反应是肥胖发生的重要危险因素
- 下丘脑病变时生理平衡失调，引起摄食过量
- 精神刺激时迷走神经兴奋、胰岛素分泌增多、食欲亢进

- Jebeile H, et al. Lancet Diabetes Endocrinol, 2022; 单浩洋等, 中国学校卫生, 2015

## KPK-03：中医病因病机

### 四大病因
1. **饮食不节**：过食肥甘厚味，损伤脾气
2. **先天禀赋**：脾肾两虚，气化失常
3. **久坐少劳**：过于安逸，伤及一身之气
4. **情志失调**：肝失疏泄，气机郁滞

### 经典依据
《素问·通评虚实论》载："肥贵人，则高梁之疾也"

### 核心病机
**脾胃运化失常，痰湿、脂膏内停**——这是儿童肥胖的总病根。

具体来说：
- 小儿脾常不足+饮食不节 → 损伤脾气 → 痰湿内生 → 胃强脾弱 → 消谷善饥 → 越吃越虚
- 安逸少动+先天不足 → 脾肾两虚 → 水湿不运 → 聚湿成痰 → 脂膏内蓄
- 情志不遂+肝郁 → 肝木乘土 → 水液不运 → 停而生饮成痰

### 病变特点
- **病变部位**：主要在脾、胃，涉及肝、肾
- **病性**：本虚标实（脏腑虚弱、津液失常为本，痰湿、脂膏积于体内为标）

- 张奇文, 朱锦善.《实用中医儿科学》, 2016

## KPK-04：7种中医体质辨识

### 什么是体质
体质是在先天遗传和后天获得的基础上共同形成的特质，决定着人们对于某些疾病的易感性与患病倾向性。准确的体质辨识有助于早期识别肥胖风险，制定因人制宜的个体化干预方案。

### 7种体质一览

| 体质类型 | 一句话特征 | 面部 | 体感 | 舌象 |
|---------|-----------|------|------|------|
| 平和质 | 健康平衡型 | 面色润泽 | 不易疲劳，精力充沛 | 舌淡红，苔薄白 |
| 气虚质 | 气力不足型 | 面色萎黄或㿠白 | 气短懒言，易疲乏，动则气喘 | 舌体胖大，边有齿痕 |
| 阳虚质 | 怕冷型 | 面色无华 | 畏冷，手足不温，精神不振 | 舌淡胖嫩，边有齿痕 |
| 痰湿质 | 湿气重型 | 面部油脂多 | 困倦嗜睡，不喜活动 | 舌胖大有齿痕，苔白腻 |
| 湿热质 | 湿热夹杂型 | 面垢油光 | 身重困倦，心烦懈怠 | 舌质偏红，苔黄腻 |
| 气郁质 | 情绪不畅型 | 忧郁面貌 | 烦闷不乐，易叹气 | 舌淡红，苔薄白 |
| 阳热质 | 火气旺型 | 面赤唇红 | 好动少静，多食易饥 | 舌质红，苔黄或白 |

### 体质判定标准
参照《儿童体质中医分型与判定标准》（赵霞,李敏, 南京中医药大学学报, 2023）

## KPK-05：诊断标准（西医BMI + 中医证型）

### 西医诊断标准
**BMI = 体重(kg) / 身高²(m²)**

| 年龄段 | 参考标准 | 超重 | 肥胖 | 重度肥胖 |
|--------|---------|------|------|---------|
| 0~5岁 | WS/T 423 | +1SD≤BMI<+2SD | +2SD≤BMI<+3SD | BMI≥+3SD |
| 6~18岁 | WS/T 586 | 按性别年龄BMI界值点判定 | 同左 | — |

### 中医证候分型（4种）

**脾虚湿阻证**
- 表现：肥胖，疲乏无力，面色少华，肢体困重，腹满，大便黏腻不爽
- 舌脉：舌质淡红，胖有齿痕，苔白腻，脉沉缓

**胃热湿阻证**
- 表现：肥胖臃肿，肢重困楚，消谷善饥，口臭，口渴不欲饮，大便秘结或稀溏
- 舌脉：舌质红，苔腻微黄，脉滑数

**脾肾两虚证**
- 表现：肥胖虚浮，动则气喘，疲乏无力，腰酸腿软，畏寒肢冷，嗜睡喜卧，大便溏薄
- 舌脉：舌质淡红，苔白，脉沉缓无力

**肝郁脾虚证**
- 表现：肥胖，胸胁胀闷，急躁易怒，胃脘痞满，大便不调，失眠多梦
- 舌脉：舌质暗红，脉细弦

- 汪受传.《中医儿科学》, 1998
- 和婧伟等.《中国儿童单纯性肥胖症临床诊治中西医结合专家共识》, 2023

## KPK-06：治未病四期概述

### 核心理念
"治未病"是中医预防医学的核心思想，在儿童肥胖管理中分为四个阶段：

```
未病先防  →  欲病救萌  →  既病防变  →  瘥后防复
（防发病）    （治初始）    （阻止进展）    （防反弹）
```

### 四期对照

| 分期 | 目标人群 | 目标 | 核心措施 |
|------|---------|------|---------|
| 未病先防 | 有高危因素但体重正常 | 减少发病率 | 膳食+运动+生活方式指导 |
| 欲病救萌 | 超重状态但未达肥胖 | 治病于初始 | 结合体质辨体施治 |
| 既病防变 | 已确诊肥胖 | 降BMI/腰围/体脂率 | 中药内服+外治+膳食运动 |
| 瘥后防复 | 减重成功后 | 持久稳定控制防止反弹 | 长期坚持健康生活方式 |

### 创新点
本指南创新性地提出"欲病救萌"阶段，使传统治未病三分期扩展为四分期，更加贴合儿童青少年肥胖的进展特点。

## KPK-07：未病先防——膳食

**适用人群**：具有肥胖高危因素的正常体重儿童
**目的**：减少肥胖的发病率
**推荐级别**：E / 强推荐

### 膳食原则（源自《黄帝内经》）
"五谷为养，五果为助，五畜为益，五菜为充"——饮食有节，谷肉果菜，食养尽之，无使过之。

### 具体建议（《中国居民膳食指南（2022）》）
- ✅ 品种多样，搭配合理
- ✅ 多吃蔬菜、奶类、全谷、大豆
- ✅ 适量吃水果、鱼禽蛋及瘦肉
- ✅ 规律一日三餐，定时定量，不暴饮暴食
- ✅ 吃好早餐，合理选择零食
- ✅ 足量饮水，不喝含糖饮料，少吃甜点
- ✅ 纠正因无聊、压力、孤独或屏幕前时间过久所致的过食

### 引用来源
- 《黄帝内经》
- 《中国居民膳食指南（2022）》

## KPK-08：未病先防——运动与生活方式

### 运动建议（推荐级别：E / 强推荐）
"动以养形，静以养神"——动静结合方可调整脏腑功能。

**各年龄段运动量**：

| 年龄段 | 每日运动量 |
|--------|-----------|
| 6岁以下 | 每天60 min身体活动 |
| 学龄期儿童 | 每天60 min中等至高强度体育活动 |
| 青春期儿童 | 每天至少90 min中等强度体育活动 |
| 额外要求 | 每周至少3 d较高强度有氧+增强肌骨锻炼 |

**安全运动建议**：
- 超重青少年运动损伤概率为正常青少年的1.386倍
- 运动开始时选太极拳、八段锦等中医特色运动（运动量小，不易损伤）
- 适应后逐步增加：快步走→慢跑→跳绳→跳舞→打乒乓球→骑自行车
- 体力较好者可选：游泳、跑步、武术、登山

### 生活方式（推荐级别：B / 强推荐）

**视屏时间**：< 2 h/天
**睡眠时间**：

| 年龄 | 每日睡眠 |
|------|---------|
| 1~2岁 | 11~14 h |
| 3~5岁 | 10~13 h |
| 6~12岁 | 9~12 h |
| 13~18岁 | 8~10 h |

### 引用来源
- 《中国儿童青少年身体活动指南》, 2017
- 杨慧超等, 当代体育科技, 2021

## KPK-09：欲病救萌——超重患儿的辨体调理（上）

**适用人群**：超重状态但未达肥胖诊断标准的患儿
**目的**：治病于初始
**推荐级别**：E / 强推荐

### 平和质
- 🍽️ 饮食：适量均衡，粗细粮合理搭配，多五谷杂粮蔬菜瓜果，少油腻辛辣，不挑食偏食
- 🛋️ 起居：保持心情舒畅、心境平和，作息规律，劳逸适度

### 气虚质
- 🍽️ 饮食：多食益气健脾之品——小米、粳米、黄豆、白扁豆、鸡肉、鱼肉、香菇、大枣、桂圆等，少食生冷
- 🛋️ 起居：活动量不宜过大，防止汗出过多，汗后及时擦拭防着凉
- 🍵 药膳：参芪鸡丝冬瓜汤（人参+黄芪+鸡丝+冬瓜煲汤）；黄芪陈皮茶（黄芪+陈皮泡水）

### 阳虚质
- 🍽️ 饮食：宜食甘温缓补之品——牛肉、羊肉、核桃、栗子、韭菜等温补阳气，忌生冷寒凉
- 🛋️ 起居：鼓励户外活动多晒太阳，活动量以微汗为度；注意足、腹、背部保暖
- 🍵 药膳：羊肉炒葱头（羊肉与洋葱爆炒）

### 痰湿质
- 🍽️ 饮食：宜食甘淡温、甘辛之品健脾利湿化痰——冬瓜、白萝卜、薏苡仁、红小豆、竹笋等，忌生冷黏滞
- 🛋️ 起居：常晒太阳或日光浴，不宜久坐久卧；运动循序渐进；鼓励积极情绪，避免懒散懈怠；居住环境宜通风避潮湿
- 🍵 药膳：荷叶茯苓粥（鲜荷叶1张+茯苓50 g+粳米50~100 g熬粥）；冬瓜薏仁粥（冬瓜150 g+薏苡仁50 g共煮）

## KPK-10：欲病救萌——超重患儿的辨体调理（下）

### 湿热质
- 🍽️ 饮食：宜食甘淡之物——赤小豆、绿豆、空心菜、黄瓜、冬瓜、藕、荸荠等；少食火锅烧烤辛温助热之物；忌油腻厚味滋腻温热（羊肉、生姜、芫荽、辣椒、饴糖、蜂蜜等）
- 🛋️ 起居：适度增加运动，保持空气流通，避免炎热潮湿环境
- 🍵 药膳：五花茶（木棉花+槐花+鸡蛋花+金银花+葛花泡水）；荷前粥（荷叶10 g+车前草10 g+冬瓜连皮50 g+粳米50~100 g熬粥）

### 气郁质
- 🍽️ 饮食：宜食舒肝解郁、调畅气机、健脾养心安神之品——小麦、蘑菇、黄花菜、丝瓜、白萝卜、金橘、山楂、玫瑰花、佛手瓜等；少辛辣刺激；忌壅塞酸收类（乌梅、酸枣、杨桃、柠檬）
- 🛋️ 起居：保持开朗豁达情绪，正确��达控制情绪；多参加体育锻炼及户外活动，减少学习压力
- 🍵 药膳：三花减肥茶（玫瑰花+茉莉花+玳玳花+川芎+荷叶泡水）；佛手当归茶（佛手5 g+当归5 g+白芍6 g+山药15 g+麦冬5 g泡水）；金桔山药小米粥（金桔20 g+鲜山药100 g+小米50 g熬粥）

### 阳热质
- 🍽️ 饮食：宜食味甘微苦、性偏寒凉，清热祛火、导滞泄热之品——苦瓜、冬瓜、丝瓜等；少食或忌食辛香辛辣肥甘温热（大蒜、大葱、洋葱、辣椒等）
- 🛋️ 起居：适度增加运动，保证充足睡眠，保持心情舒畅，勿令阳亢
- 🍵 药膳：竹叶粥（鲜竹叶或鲜淡竹叶6 g+粳米50 g熬粥）

## KPK-11：既病防变——中药内服

**适用人群**：已确诊为肥胖的儿童青少年
**目的**：降低BMI、腰围、体脂率，阻断或延缓疾病传变
**推荐级别**：E / 强推荐

### 脾虚湿阻证
**治法**：健脾益气，化湿消脂
**推荐方药**：参苓白术散合平胃散加减
**常用药**：党参、白术、苍术、厚朴、陈皮、干姜、炙甘草、茯苓、山楂
**加减**：
- 气虚甚者 → 加黄芪
- 腹满明显者 → 加木香、香附、枳壳
- 湿盛者 → 加薏苡仁、冬瓜子

### 胃热湿阻证
**治法**：清胃泻热，除湿利浊
**推荐方药**：泻黄散加味
**常用药**：防风、藿香、栀子、石膏、薏苡仁、泽泻、荷叶、厚朴、黄连
**加减**：
- 大便秘结者 → 加熟大黄、瓜蒌
- 口渴多饮者 → 加麦冬、天花粉、石斛
- 湿盛者 → 倍薏苡仁、荷叶或加佩兰、砂仁

### 脾肾两虚证
**治法**：健脾益气，补肾温阳
**推荐方药**：苓桂术甘汤合真武汤加减
**常用药**：茯苓、桂枝、白术、甘草、白芍、生姜、附子
**加减**：
- 形寒肢冷者 → 加肉桂
- 腰膝酸软者 → 加杜仲、牛膝
- 浮肿重+气短气虚者 → 重加黄芪、山药
- 湿重苔腻者 → 加苍术、白扁豆、泽泻
- 汗多者 → 加浮小麦、煅牡蛎、五味子
- 浮肿明显者 → 加车前子、猪苓

### 肝郁脾虚证
**治法**：疏肝理气，健脾助运
**推荐方药**：柴胡疏肝散加味；逍遥散加减
**常用药（柴胡疏肝散）**：柴胡、香附、川芎、陈皮、枳壳、白芍、甘草
**常用药（逍遥散）**：柴胡、当归、白芍、白术、茯苓、薄荷、生姜、甘草
**加减**：
- 瘀血征象明显者 → 加山楂、丹参、桃仁
- 胸胁胀痛者 → 加延胡索、郁金
- 失眠多梦者 → 加酸枣仁、远志
- 嗳气吞酸、口苦者 → 合用左金丸，加旋覆花

### 膳食管理（确诊肥胖儿童）
对于已确诊肥胖的儿童，在中药治疗的同时，需配合膳食管理。

**宏量营养素供能比**（参照《中国儿童单纯性肥胖症临床诊治中西医结合专家共识》《中国居民膳食指南（2022）》）：

| 营养素 | 供能比 |
|--------|-------|
| 蛋白质 | 15%~20% |
| 脂肪 | 25%~30% |
| 碳水化合物 | 50%~55% |

**膳食管理要点**：
- 家庭成员共同参与，逐步建立健康饮食习惯
- 规律定时进食，控制总摄入量
- 减少高脂高钠高糖深加工食品、快餐、饮料
- 减少外出就餐
- 进食速度不宜过快，每餐20~30 min
- 避免进食时看电子产品
- 根据能量密度将食物分为优选（绿灯）、限制（黄灯）、不宜（红灯）3类

**运动管理**：
- 6岁以下每天60 min身体活动
- 学龄期每天60 min中高强度体育活动
- 青春期每天至少90 min中等强度体育活动
- 中等强度运动：中快走、中速游泳、有氧运动、舞蹈
- 高强度运动：骑自行车、跑步、踢足球、打篮球

**⚠️ 重要提示**
- 不建议通过过度节食减重
- 不建议短期内（<3个月）快速减重
- 避免减重-复胖的反跳循环
- 中药方剂须经中医师辨证开具，不可自行抓药服用！

## KPK-12：既病防变——外治法

**适用人群**：已确诊肥胖的儿童青少年
**重要提示**：外治法须由专业中医师操作，不可自行模仿！

### 耳穴贴压（推荐级别：B / 强推荐）

| 证型 | 选穴 |
|------|------|
| 主穴（通用） | 饥点、口、胃、脾、神门、三焦、大肠、小肠、皮质下、内分泌 |
| 脾虚湿阻证 | 脾、饥点、胃、膀胱、肾、三焦、肺、皮质下、肝 |
| 胃热湿阻证 | 饥点、大肠、小肠、胃、心、交感、胆 |
| 脾肾两虚证 | 脾、肾、饥点、内分泌、膀胱、三焦 |
| 肝郁脾虚证 | 口、肝、胆、神门、皮质下、内分泌 |

操作：每次取6~7个耳穴，耳穴压丸贴片或揿针贴压，饥饿时/餐前10 min自行按压3 min。两耳交替，隔日更换1次，10次为1疗程。

### 推拿（推荐级别：C / 强推荐，多用于6岁以下儿童）
**基础取穴**：神阙、天枢、气海、关元、中极、脾俞、胃俞、大肠俞、臂臑、曲池、风市、委中、承山、梁丘、足三里、丰隆

**辨证加减**：
- 脾虚湿阻证：按揉中脘、丰隆、阴陵泉各1 min
- 胃热湿阻证：按揉内庭、曲池、上巨虚各1 min
- 脾肾两虚证：按揉肾俞、命门、太溪各1 min，掌擦肾俞、命门及督脉透热
- 肝郁脾虚证：按揉肝俞、太冲、三阴交各1 min，掌按小腿内侧3~5遍

**手法**：点按法、按揉法、拿揉法、捻揉法、滚法、推法、摩法、擦法
**周期**：每天1次，每周连续5 d休息2 d，10次为1疗程

**其他**：
- 捏脊：拇食指提捏从腰骶部至大椎穴，3遍/次，每日3次
- 摩腹揉脐：推摩全腹并按揉脐部，每日100遍，30 d为1疗程

### 针刺（推荐级别：C / 强推荐）
**主穴**：中脘、水分、关元、天枢、大横、曲池、支沟、内庭、丰隆、上巨虚、三阴交、阴陵泉

**辨证加减**：
- 脾虚湿阻证：加内关、足三里
- 胃热湿阻证：加合谷
- 脾肾两虚证：加气海、脾俞、肾俞、足三里
- 肝郁脾虚证：加太冲、期门、合谷

**操作**：常规消毒，辨证补泻手法。毫针刺入，得气后行中等刺激，留针30~40 min。
**周期**：每日1次，10次为1周期

- GB/Z 40893.3—2021《中医技术操作规范 儿科 第3部分：小儿针灸疗法》

## KPK-13：五维健康教育

### 1. 心理健康教育
- 儿童时期是身心发展的关键时期，青春期儿童心理更加敏感脆弱
- 肥胖易使儿童青少年产生孤僻、焦虑、抑郁等心理问题
- 应加强心理健康教育，适时评估心理偏差
- 对孩子进行心理卫生教育，使之能自觉控制饮食、参加体育锻炼、正视自我
- 必要时请心理医生干预

### 2. 家庭责任
- 父母及看护人是儿童成长的第一责任人
- 学会合理搭配食物，提供健康饮食方案
- 营造良好家庭氛围，全家调整生活方式
- 积极引导儿童体育锻炼，控制视屏时间<2 h/天
- 保障睡眠时间，做好体重及生长发育监测

### 3. 医院宣教
- 加强肥胖危害的健康教育，宣传"治未病"重要性
- 将治未病理念纳入孕前和孕期检查，从胎儿期开始宣教
- 做好健康管理服务，知识普及+技能指导+咨询服务

### 4. 学校管理
- 做好健康意识教育，办好健康课堂
- 保证在校身体活动时间，合理安排体育课及课外锻炼
- 将体育成绩纳入学校考核标准

### 5. 社会宣传
- 大力宣传肥胖治未病的必要性及重要意义
- 保障社区活动场所设施齐全
- 加强对学校、医院、社区的监督，整体推进

### 引用来源
- 国家卫生健康委等.《儿童青少年肥胖防控实施方案》, 2020
